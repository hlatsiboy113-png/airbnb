# unclassified/ — unknown-source images

Files in this folder have ambiguous provenance or unclear meaning. They are
**not** assigned evidence IDs and do **not** support rubric rows.

Process:
1. Move the image here instead of the functional folder until identified.
2. Add a line to `../screenshot-register.md` "unclassified" section: filename,
   path, date, why it is unclassified.
3. If it is identified as genuine project evidence, move it to its category
   folder, add it to the register, and remove the unclassified note.

Current content: **none** — while the repo contains no genuine screenshots,
nothing is unclassified either.
